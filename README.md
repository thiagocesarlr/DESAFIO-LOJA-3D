## Tecnologias Utilizadas
- **HTML5:** Estruturação das páginas (`index.html` e `loja.html`).
- **CSS3:** Estilização visual, uso de Grid/Flexbox e ajustes de proporção de imagens (`object-fit: contain`).
- **JavaScript (ES6):** Manipulação de elementos do DOM (`document.getElementById`), laços de repetição, condicionais e simulação de formas de pagamento com desconto via Pix.

## Instruções de Execução
1. Clone ou baixe este repositório para o seu computador.
2. Certifique-se de que os arquivos `index.html`, `loja.html`, `style.css`, `script.js` e a pasta `assets/` (com as imagens) estão no mesmo diretório.
3. Abra o arquivo `index.html` em qualquer navegador web para iniciar pela página de apresentação.
